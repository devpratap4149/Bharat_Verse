# 🇮🇳 BharatVerse

### Discover the India beyond the obvious.

> 🌐 **Live Website:** https://bharat-verse-mhmx.vercel.app/

BharatVerse is a cultural discovery platform designed to help travellers explore **India's hidden heritage, forgotten stories, local artisans, traditional crafts, and underrated destinations** beyond the usual tourist circuit.

The platform combines immersive exploration, personalized discovery, and an AI-powered guide to make discovering India's cultural richness more meaningful.

---

## ✨ Features

### 🗺️ Explore Hidden India

Discover lesser-known heritage sites, cultural landmarks, historic places, and underrated destinations across India.

### 🏛️ Destination Information

Explore detailed information about destinations including:

* History and cultural significance
* Best time to visit
* Location
* Images
* Related destinations
* Storytelling content

### 🤖 BharatVerse AI Guide

An AI-powered guide that helps users discover:

* Hidden destinations
* Heritage sites
* Traditional crafts
* Local artisans
* Underrated places
* Cultural experiences

### 🎥 Storytelling Experience

Selected destinations include embedded video content, allowing users to experience the story of a place directly within BharatVerse.

### ❤️ Personalized Discovery

Recommendations can consider traveller preferences such as:

* Interests
* Budget
* Available time
* Crowd preference
* Accessibility requirements

### ♿ Accessibility Awareness

The platform considers accessibility and senior-friendly travel when presenting destinations.

## 🎯 Problem We Are Solving

India has enormous cultural and historical wealth, but tourism is often concentrated around a relatively small number of famous destinations.

Many lesser-known heritage sites, traditional crafts, historic towns, and local cultural experiences remain under-discovered.

**BharatVerse aims to bridge this gap by connecting travellers with the India that exists beyond mainstream tourism.**

---

## 💡 Our Vision

> **From tourist spots to living stories.**

We believe travel should be more than checking famous places off a list.

It should be about discovering the people, traditions, architecture, crafts, history, and stories that make every part of India unique.

## 🧠 Recommendation Foundation

BharatVerse uses a structured destination dataset to organize information about places and provide a foundation for personalized recommendations.

Destination data can include:

```js
{
  id: 1,
  name: "Ramnagar Fort",
  city: "Varanasi",
  description: "...",
  history: "...",
  significance: "...",
  bestTime: "October to March",
  lat: 25.2675,
  lng: 83.0217
}
```

This structure can be expanded into a more advanced recommendation system using traveller preferences such as budget, time, interests, crowd level, and accessibility.

## 🚀 Getting Started

### Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd BharatVerse_New
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

The application will normally run at:

```text
http://localhost:5173
```

### Build for production

```bash
npm run build
```
